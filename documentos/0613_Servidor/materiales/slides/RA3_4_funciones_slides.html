Parámetros, retorno, tipos declarados

Qué es una función

En 2.4 adelantamos su sintaxis mínima; en 2.5 escribimos mostrarCurriculo(). Ahora las formalizamos.

  • Reutilizar: se escribe una vez, se llama muchas
  • Dar nombre: horasRestantes(2000, 1350) se entiende mejor que la resta suelta
  • Aislar: cada función tiene su propio ámbito (2.4)

Parámetros y valor de retorno


<?php
  function horasRestantes(int $horasTotales, int $horasCursadas): int
  {
      return $horasTotales - $horasCursadas;
  }

  $pendientes = horasRestantes(2000, 1350);   // 650
  echo '<p>Horas restantes: ', $pendientes, '</p>';
?>

Los argumentos se asignan a los parámetros por orden. return termina la función y entrega el resultado.

Devolver, mejor que mostrar

Compara con mostrarCurriculo() de 2.5, que hacía echo dentro.

Quien la llama decide qué hacer con el resultado…
y se puede comprobar automáticamente.

A partir de ahora, salvo que su propósito sea generar salida, nuestras funciones devolverán valores.

Valor por defecto

Se usa si no se pasa ese argumento. Va siempre al final.


<?php
  function titulacion(string $grado = 'Superior'): string
  {
      return match ($grado) {
          'Superior' => 'Técnico Superior',
          'Medio'    => 'Técnico',
          default    => 'Titulación desconocida',
      };
  }

  echo titulacion();          // Técnico Superior
  echo titulacion('Medio');   // Técnico
?>

Desde PHP 8, argumentos con nombre: horasRestantes(horasCursadas: 1350, horasTotales: 2000).

Por valor y por referencia

Los argumentos se pasan por valor: la función recibe una copia (como los arrays, 3.3).

Con & antes del parámetro: por referencia, y la función trabaja sobre la original.

Así está declarada sort(array &$array): por eso modifica el array en vez de devolver uno nuevo. En nuestras funciones no usaremos referencias: preferimos devolver.

Tipos declarados

int $horasTotales y : int tras los paréntesis (como array $curriculo en 2.5).

DeclaraciónSignifica
int, float, string, bool, arrayEse tipo exactamente
?stringTipo nullable: un string o null
int|floatTipo unión: cualquiera de los dos

Y, solo en el retorno, : void ("no devuelve nada").

Un tipo nullable

Un currículo puede no tener vídeo todavía.


<?php
  function enlaceVideo(?string $video): string
  {
      if ($video === null || $video === '') {
          return 'Sin vídeo';
      }
      return '<a href="' . $video . '">vídeo</a>';
  }
?>

¿Por qué declarar tipos?

  • Los errores aparecen antes y en su sitio: en la llamada, no varias líneas después
  • La firma documenta la función: se sabe qué recibe y qué devuelve sin leer su código
  • Las herramientas lo aprovechan: editores, analizadores estáticos y asistentes de IA generan código más correcto

Modo estricto: strict_types

Por defecto PHP convierte argumentos (modo coercitivo): horasRestantes('2000', 1350) funciona. El mismo problema que ==.


<?php
declare(strict_types=1);

Como primera sentencia del fichero. Con ella, esa llamada lanza TypeError.

Afecta a las llamadas desde el fichero que lo declara, no a las funciones definidas en él. Lo comprobarás en el último ejercicio.

Regla de este REA

Todos los ficheros PHP, a partir de ahora,
empiezan por declare(strict_types=1);

El de las funciones y también las páginas que las llaman.

Funciones flecha (fn)

array_map(), array_filter() y usort() (pendientes de 3.3) reciben otra función como argumento.


<?php
  // de cada currículo, solo el nombre del alumno
  $alumnos = array_map(fn(array $curriculo): string => $curriculo['alumno'], $curriculos);
  // ['Ana López', 'Marcos Pérez', 'Laura García']
?>

Cuerpo: una única expresión, que se devuelve sola.

Una función flecha ve su ámbito


<?php
  $codCiclo = 'DAW';
  $deDaw = array_filter(
      $curriculos,
      fn(array $curriculo): bool => $curriculo['ciclo'] === $codCiclo
  );
?>

array_filter() conserva las claves: si solo queda el elemento 2, el resultado es [2 => ...]. Para reindexar: array_values() (3.3).

usort() con <=>

El callback devuelve negativo, cero o positivo. Justo lo que hace el operador spaceship investigado en 2.3.


<?php
  usort($curriculos, fn(array $a, array $b): int => $a['alumno'] <=> $b['alumno']);
?>

Funciones anónimas

Cuando el cuerpo necesita varias sentencias. A diferencia de fn, no ve las variables de fuera (2.4) salvo use.


<?php
  $deDaw = array_filter($curriculos, function (array $curriculo) use ($codCiclo): bool {
      return $curriculo['ciclo'] === $codCiclo;
  });
?>

Organizar las funciones en ficheros


<?php
declare(strict_types=1);

require_once __DIR__ . '/../src/RA3_funciones.php';
?>
  • require_once: incluye y ejecuta, pero solo la primera vez
  • require/include(_once): si falta el fichero, uno detiene el script y el otro solo avisa
  • __DIR__: la carpeta del fichero actual
Para cargar código del que depende la página, usaremos siempre require_once.

Dos reglas para src/

  1. Va fuera de public/. nginx solo sirve public/ (2.1): src/ se carga desde PHP, nadie lo pide desde el navegador.
  2. Solo define, no ejecuta. Sin echo ni HTML. Así un test puede cargarlo y llamar a las funciones directamente, sin petición HTTP.

Puente al Bloque 4. En Laravel, Composer genera un autoload: incluye cada fichero solo. Versión automatizada de lo que aquí hacemos a mano.
