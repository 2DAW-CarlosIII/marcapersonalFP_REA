Bucle

Repite un bloque de sentencias
mientras se cumpla una condición,
o una vez por cada elemento.

Cada repetición: una iteración. PHP tiene cuatro bucles: while, do-while, for y foreach.

while

Comprueba la condición antes de cada iteración. Adecuado cuando no sabemos cuántas veces hará falta repetir.


<?php
  $horasCiclo    = 2000;
  $horasPorAnio  = 700;
  $horasCursadas = 0;
  $anios         = 0;

  while ($horasCursadas < $horasCiclo) {
    $horasCursadas += $horasPorAnio;
    $anios++;
  }

  echo '<p>Años necesarios: ', $anios, '</p>';   // 3
?>
$anios++ es el operador de incremento (ya usado sin detenerse en 2.4): suma 1, equivale a $anios += 1. $anios-- resta 1.

Cuidado con los bucles infinitos

Si nada dentro del bucle hace que la condición llegue a ser false, no termina nunca.

En el servidor, PHP lo corta al superar un tiempo máximo de ejecución: la petición acaba en error. Lo investigarás en el último ejercicio.

do-while

Comprueba la condición después: el bloque se ejecuta al menos una vez.


<?php
  $intentos = 0;

  do {
    $intentos++;
    echo '<p>Intento ', $intentos, '</p>';
  } while ($intentos < 0);   // falsa desde el principio
?>

Aun así, se ve "Intento 1". En aplicaciones web se usa poco; conviene reconocerlo.

for

Cuando hay un contador: inicialización, condición y actualización, en una sola línea.


for (inicialización; condición; actualización) {
    // sentencias
}
  1. La inicialización: una sola vez, al principio
  2. La condición: antes de cada iteración
  3. La actualización: al final de cada iteración

Un desplegable de años


<?php
  echo '<select name="promocion">';
  for ($anio = 2020; $anio <= 2025; $anio++) {
    echo '<option value="', $anio, '">', $anio, '</option>';
  }
  echo '</select>';
?>

Seis opciones, de 2020 a 2025, generadas por el servidor. Cambiar el rango es tocar un número.

foreach: recorrer un array

Sin contador y sin condición: una vez por cada elemento. La respuesta al ejercicio de investigación de 2.5.


<?php
  $curriculos = [
    ['alumno' => 'Ana López', 'ciclo' => 'DAW', 'video' => '…'],
    ['alumno' => 'Marcos Pérez', 'ciclo' => 'DAM', 'video' => '…'],
    ['alumno' => 'Laura García', 'ciclo' => 'ASIR', 'video' => '…'],
  ];

  echo '<ul>';
  foreach ($curriculos as $curriculo) {
    echo '<li class="curriculo">', $curriculo['alumno'], ' — ', $curriculo['ciclo'], '</li>';
  }
  echo '</ul>';
?>

Da igual 3 o 300 currículos: el código es el mismo. Si el array está vacío, el bloque no se ejecuta ninguna vez.

foreach con clave

Con un array asociativo, también la clave: clave => valor.


<?php
  $curriculo = ['alumno' => 'Ana López', 'ciclo' => 'DAW', 'video' => '…'];

  echo '<dl>';
  foreach ($curriculo as $campo => $valor) {
    echo '<dt>', $campo, '</dt><dd>', $valor, '</dd>';
  }
  echo '</dl>';
?>

En un array indexado, la clave es la posición (0, 1, 2…). 3.3 verá los arrays en profundidad.

¿for o foreach para un array? Se podría con for ($i = 0; $i < count($curriculos); $i++) y $curriculos[$i], pero foreach es más corto, no necesita contador y funciona también con arrays asociativos, que no tienen posiciones. Para recorrer arrays, usar siempre foreach.

break y continue

continue

Salta el resto de esta iteración y pasa a la siguiente.

break

Termina el bucle por completo.

Es la primera vez que combinamos un bucle y una decisión: lo haremos constantemente.

En código


<?php
  // continue: listar solo los currículos que tienen vídeo
  foreach ($curriculos as $curriculo) {
    if ($curriculo['video'] === '') {
      continue;
    }
    echo '<li>', $curriculo['alumno'], '</li>';
  }

  // break: parar en cuanto encontramos el primer currículo de DAM
  foreach ($curriculos as $curriculo) {
    if ($curriculo['ciclo'] === 'DAM') {
      echo '<p>Primer currículo de DAM: ', $curriculo['alumno'], '</p>';
      break;
    }
  }
?>

Bucles en el HTML: sintaxis alternativa

Como en 3.1 con if: foreach (...): ... endforeach; (también for:/endfor;, while:/endwhile;).


<table>
  <tr><th>Alumno</th><th>Ciclo</th></tr>
  <?php foreach ($curriculos as $curriculo): ?>
    <tr>
      <td><?= $curriculo['alumno'] ?></td>
      <td><?= $curriculo['ciclo'] ?></td>
    </tr>
  <?php endforeach; ?>
</table>

La etiqueta corta <?= ?>

Equivale a <?php echo ...; ?>: pensada para insertar un valor en medio del HTML.

Con ella y la sintaxis alternativa, la página se lee como HTML con "huecos" que rellena el servidor.

En el Bloque 4, Blade: @foreach ... @endforeach y {{ $curriculo['alumno'] }}.

Aviso. <?= ?> escribe el valor tal cual. Cuando los datos vengan del usuario (3.6) habrá que escaparlos. Blade, con {{ }}, lo hace automáticamente.

Lo esencial

  • while: comprueba antes; do-while: comprueba después (al menos una vez)
  • for: cuando hay un contador con inicio, fin y paso
  • foreach: para recorrer arrays, siempre
  • continue salta la iteración; break termina el bucle
  • Sintaxis alternativa + <?= ?> para HTML con "huecos"
