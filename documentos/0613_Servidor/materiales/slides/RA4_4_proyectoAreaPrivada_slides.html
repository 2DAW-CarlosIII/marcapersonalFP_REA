El diseño: "Mi currículo"

  • Solo para alumnos. Un docente recibe un 403.
  • Un currículo por alumno, como User y Curriculo (1:1, con Eloquent en el Bloque 6), en $_SESSION['curriculo'].
  • La misma página da de alta y edita: formulario si no hay currículo; si lo hay, se muestra con un enlace "Editar".
  • Al guardar: POST/Redirect/GET y mensaje flash, como en 4.1.

Sabemos quién es, pero no puede

exigirRol(), nueva

exigirRol()


function exigirRol(string $rol): array
{
    $usuario = exigirLogin();
    if ($usuario['rol'] !== $rol) {
        http_response_code(403);
        exit('No tienes permiso para ver esta página.');
    }
    return $usuario;
}

Primero, que haya usuario; después, su rol. exit() admite un texto, que se envía antes de terminar.

El alumno sale de la sesión

Con F12, cualquiera añadiría al formulario un campo alumno con otro nombre:


$datos = [
    'alumno' => $usuario['firstName'] . ' ' . $usuario['lastName'],   // de la sesión
    'ciclo'  => $_POST['ciclo'] ?? '',                                 // del formulario
    'video'  => $_POST['video'] ?? '',                                 // del formulario
];

Lo que identifica al usuario, o decide qué datos son "suyos", nunca sale del cliente.

Ocultar no es proteger

En el perfil, el enlace "Mi currículo" solo lo ven los alumnos:


<?php if ($usuario['rol'] === 'alumno'): ?>
  <p><a href="RA4_miCurriculo.php">Mi currículo</a></p>
<?php endif; ?>

Es comodidad, no seguridad: quien escriba la dirección a mano llega igual. Lo que protege la página es exigirRol().

¿Y si cierro la sesión?

El currículo desaparece

El logout destruye la sesión; al volver a entrar, session_regenerate_id() da un identificador nuevo y vacío.

Y Elena, la docente, nunca podría ver los currículos de sus alumnos: cada sesión es de un navegador.

La conclusión del bloque

La sesión sirve para recordar a un usuario mientras navega…

…pero no es un almacén de datos

Para que sobreviva al cierre de sesión y otros usuarios puedan consultarlo: un sitio compartido y permanente, la base de datos (Bloque 6).
