Escalares y compuestos

En 2.3, tipos escalares (int, float, string, bool): un único valor. Dos tipos compuestos agrupan varios:

array

Colección ordenada de pares clave → valor. El protagonista de hoy.

object

Instancia de una clase: datos + comportamiento. Lo vemos en 3.5.

2.5 adelantó lo mínimo; 3.2 los recorrió con foreach. Ahora los formalizamos.

Crear arrays

Con corchetes. Cada elemento tiene una clave: un int o un string.


<?php
  // Indexado: PHP asigna las claves 0, 1, 2... automáticamente
  $ciclos = ['DAW', 'DAM'];

  // Asociativo: las claves las elegimos nosotros
  $ciclo = ['codCiclo' => 'DAW', 'grado' => 'Superior', 'horas' => 2000];

  // Array vacío, para rellenarlo después
  $modulos = [];
?>

En código antiguo verás también array('DAW', 'DAM'): equivalente. Aquí usaremos siempre corchetes.

Modificar arrays


<?php
  $ciclos[] = 'ASIR';          // añade al final, con la siguiente clave libre (2)
  $ciclo['horas'] = 2000;      // modifica el valor de una clave existente
  $ciclo['familia_id'] = 1;    // si la clave no existe, la crea
  unset($ciclo['familia_id']); // elimina un elemento

  echo count($ciclos);         // 3
?>

Inspeccionar un array

var_dump() (2.3) sigue sirviendo; print_r() da una salida más compacta.


<?php
  echo '<pre>';
  print_r($ciclo);
  echo '</pre>';
?>

El <pre> hace que el navegador respete los saltos de línea.

Arrays multidimensionales

El valor de un elemento puede ser, a su vez, otro array.


<?php
  $ciclo = [
    'codCiclo' => 'DAW',
    'nombre'   => 'Desarrollo de Aplicaciones Web',
    'modulos'  => [
      '0612' => 'Desarrollo web en entorno cliente',
      '0613' => 'Desarrollo web en entorno servidor',
    ],
  ];

  echo $ciclo['modulos']['0613'];   // Desarrollo web en entorno servidor
?>

Cada corchete baja un nivel. El $curriculos de 2.5 también era multidimensional.

Para recorrer un nivel interior: foreach ($ciclo['modulos'] as $codigo => $nombre) { ... }, exactamente como cualquier otro array. Los arrays multidimensionales son la forma más habitual de representar una lista de registros, la que obtendremos de una base de datos (Bloque 5).

Buscar


<?php
  $ciclos = ['DAW', 'DAM', 'ASIR'];

  in_array('DAM', $ciclos, true);            // true: ¿existe ese valor?
  array_search('ASIR', $ciclos, true);       // 2: ¿en qué clave está?
  array_key_exists('grado', $ciclo);         // ¿existe esa clave?
?>

El tercer argumento true: comparación estricta (===). Sin él, ==. Coherentes con 2.3, lo escribiremos siempre.

isset() frente a array_key_exists(): isset($ciclo['grado']) devuelve false si la clave existe y su valor es null. Cuando esa diferencia no importa, isset() es lo más habitual (y el operador ?? de 3.1 se comporta igual que isset()).

Extraer y combinar


<?php
  array_keys($ciclo);                            // ['codCiclo', 'nombre', 'modulos']
  array_values($ciclo['modulos']);               // los valores, reindexados desde 0
  array_column($curriculos, 'alumno');           // de una lista de registros, un solo campo
                                                  //   ['Ana López', 'Marcos Pérez', ...]
  array_merge(['DAW', 'DAM'], ['ASIR', 'SMR']);  // ['DAW', 'DAM', 'ASIR', 'SMR']
?>

array_column() merece atención: saca una "columna" de una lista de registros.

Arrays ↔ strings


<?php
  echo implode(', ', ['DAW', 'DAM', 'ASIR']);   // "DAW, DAM, ASIR"
  $ciclos = explode(',', 'DAW,DAM,ASIR');       // ['DAW', 'DAM', 'ASIR']
?>

implode() une con un separador; explode() parte por un separador.

Ordenar


<?php
  $ciclos = ['DAW', 'ASIR', 'DAM'];
  sort($ciclos);    // ['ASIR', 'DAM', 'DAW']
?>

Ojo: sort() no devuelve el array ordenado: modifica el que le pasas (y devuelve true).

rsort() al revés; asort()/ksort() conservan claves, por valor o por clave. array_map(), array_filter(), usort() reciben otra función: las vemos en 3.4.

Desestructuración

Extrae varios elementos a variables sueltas, en una sola sentencia.


<?php
  [$primero, $segundo] = ['DAW', 'DAM', 'ASIR'];
  echo $primero;   // DAW
?>
        

<?php
  ['alumno' => $alumno, 'ciclo' => $codCiclo] = $curriculos[1];
  echo '<p>Segundo currículo: ', $alumno, ' (', $codCiclo, ')</p>';
?>

También en la cabecera de un foreach.

Los arrays se copian

Al asignar un array a otra variable (o pasarlo a una función), PHP hace una copia.


<?php
  $copia = $curriculos;
  $copia[] = ['alumno' => 'Pablo Ruiz', 'ciclo' => 'DAW', 'video' => ''];

  echo count($curriculos);   // 3: el original no ha cambiado
  echo count($copia);        // 4
?>

Lo recordaremos en 3.5: con los objetos no ocurre lo mismo.

Puente al Bloque 4: Laravel envuelve los arrays en colecciones (Collection), con métodos encadenables: collect($curriculos)->pluck('alumno')->sort() hace lo mismo que array_column() + sort(). Por debajo sigue habiendo un array de PHP.

Lo esencial

  • Indexado o asociativo; pueden anidarse (multidimensionales)
  • in_array()/array_search() con tercer argumento true: comparación estricta
  • array_column(), implode()/explode(), sort() y desestructuración
  • Los arrays se copian al asignarlos; los objetos, no (3.5)
